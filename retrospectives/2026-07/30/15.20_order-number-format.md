## Lessons Learned

- **Pattern**: script แปลง string หลายจุดที่ต้อง "จับคู่กันเป็น pair" (เช่น `id`===`code` ในหนึ่ง record) ห้ามใช้ counter ที่เพิ่มทีละ match แบบ flat เพราะ match ลำดับที่ 1 กับ 2 อาจเป็น field คนละตัวในคนละ record — ต้อง key ด้วยค่าที่ฝังอยู่ในตัว string เดิม (เช่น running number เดิม) เพื่อให้ pair เดียวกันได้ค่าใหม่เดียวกันเสมอ. **Why**: รอบแรกใช้ counter แบบ flat ทำให้ `id`/`code` ของ record เดียวกันได้เลขคนละตัว (ละเมิด invariant `id`=`code`) ต้อง `git checkout` แล้วเขียนใหม่ — เสียเวลาเปล่า ตรวจ diff ก่อน commit ทุกครั้งช่วยจับได้แต่ key ให้ถูกตั้งแต่แรกดีกว่า.
- **Discovery**: task-gate.sh/gate-task.sh ต้องการบรรทัด `Evidence:` ขึ้นต้นตรงๆ (mixed indent ได้ แต่ห้ามมี `- ` bullet นำหน้าคำว่า Evidence) — เขียนแบบ `  - Evidence: ...` จะไม่ match regex แล้ว block. **Why**: เจอ hook fail 2 รอบเพราะ format ผิด ต้องแก้ทุก task ในไฟล์เดียวกันพร้อมกันด้วย Write ไม่ใช่ Edit ทีละจุด (เพราะ Edit ทีละจุด trigger hook ทีละครั้ง จุดที่ยังไม่แก้จะ fail ซ้ำ) — ครั้งหน้าเขียน Evidence line ให้ตรง format `Evidence: ...` (ไม่มี bullet ซ้อน) ตั้งแต่แรก.
