## Lessons Learned

- **Pattern**: slash-command/skill ที่ฝัง expected repo (`/spec-sync-github` คาด `metrodiesign/spec-driven-development`) — ยืนยัน remote จริงด้วย `git remote -v` ก่อนเขียน issue เสมอ; เคสนี้ remote จริง = `metrodiesign/pol-admin`. — **Why**: ถ้าเชื่อ default ของ skill จะสร้าง issue ผิด repo (หรือ fail) — confirm ground truth ถูกกว่าตามตัวอย่างใน prose.
- **Discovery**: หนึ่ง full-page view รับ optional `source` prop เสิร์ฟได้ทั้ง create และ duplicate (route `?from=code` -> server page หา role -> ส่ง `source`; ไม่มี source = create เปล่า, มี = prefill + `makeCopyCode`). — **Why**: เพิ่มหน้า duplicate โดยไม่ทำ component ซ้ำ; ตัด dialog ออกได้ทั้งตัว (ลบ orphan) — แยก route แต่ reuse logic.
- **Pattern**: เพิ่ม field ลง domain type ที่ถูกใช้หลายที่ (Role/RoleFormInput) แล้วพึ่ง `npm run build` (TS strict) จับจุดที่ลืม init — ทุก call-site ที่ construct object จะ error จนเติมครบ. — **Why**: ใช้ typechecker เป็น checklist ของ "เพิ่มทุกหน้า" แทนการไล่หาเองด้วยตา.
