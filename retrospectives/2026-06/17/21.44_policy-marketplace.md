## Lessons Learned

- **Pattern**: เพิ่มเมนู sidebar ในโปรเจกต์นี้ต้องแก้ **สองไฟล์** — `nav-config.ts` (breadcrumb/search) + `minimals-nav-config.ts` (sidebar จริงที่ `MinimalsLayout` render). — **Why**: แก้ไฟล์เดียวเมนูไม่ขึ้น; เสีย round-trip verify. (promote → `.ai/shared/stack/nextjs.md`)
- **Pattern**: เมื่อ user สั่ง "ทำให้เหมือนหน้า X" ให้ Read component จริงของหน้านั้นแล้วลอก token/structure ตรงๆ ไม่เดาจาก screenshot — reference ในโปรเจกต์เป็น source of truth (เคสนี้ `roles-columns.tsx` action button, invoice `DateInput`, `user-list-toolbar`). — **Why**: เดา token ผิด = iterate ซ้ำหลายรอบ; ลอกจากไฟล์จริงรอบเดียวจบ.
- **Discovery**: invoice/list date filter เป็น free-text decorative (ปุ่ม calendar ไม่มี picker, filter ไม่ wire). ลอก look ได้แต่ถ้าต้องการ filter จริงต้อง guard ค่าด้วย regex `YYYY-MM-DD` เต็มก่อน apply — partial typing จะ filter พังถ้าไม่ guard. — **Why**: match reference visual โดยไม่ทำ UX พัง.
