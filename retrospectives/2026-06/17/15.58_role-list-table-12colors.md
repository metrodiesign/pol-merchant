## Lessons Learned

- **Discovery**: Tailwind v4 default palette (`orange`/`teal`/`indigo`/`violet`/`pink` ...) ยังใช้ได้ควบคู่กับ custom `@theme --color-*` ตราบใดที่ไม่ได้ reset ด้วย `--color-*: initial` — ไม่ต้องนิยาม token เองครบทุกสี. — **Why**: ขยายชุดสีจาก 6 semantic families เดิมไป 12 ได้ทันทีโดยไม่แตะ globals.css.
- **Pattern**: ยืนยันว่า utility class ที่เพิ่งใช้ถูก generate จริง = grep "substring" (เช่น `orange`, `teal`) ในไฟล์ prod CSS ก้อนใหญ่ (`.next/static/chunks/*.css`) โดยตรง — **ไม่ใช่** fixed-string grep ชื่อ class เต็มข้ามหลายไฟล์ (ผ่าน `$VAR` expansion + minification ทำให้ได้ 0 หลอก). — **Why**: build เขียวไม่การันตีว่า class ถูก emit (unknown utility = เงียบ ไม่ error); ต้องเช็ค CSS จริง.
- **Pattern**: แก้ shared component (`TextField`/`SelectField`) เพื่อ fix อาการในหน้าเดียว = กระทบทุกหน้าที่ใช้ — บอก scope ที่กระทบให้ user รู้ก่อนลงมือ แล้วเลือกลบสไตล์ที่ซ้ำซ้อน (label `opacity-60` ซ้ำกับ input box ที่จางอยู่แล้ว) แทนการเพิ่ม prop ใหม่. — **Why**: กัน flexibility เกินจำเป็น + กัน regression เงียบในโมดูลอื่น.
