## Lessons Learned

- **Pattern**: task-gate `Evidence:` ต้องเป็น plain indented line ไม่ใช่ markdown bullet (`- Evidence:` awk ไม่ match) + gate รัน `npm test` เป็น code-green — **Why**: เสีย 2 รอบ block ก่อนเข้าใจ format. promoted → `.ai/shared/LESSONS.md`.
- **Pattern**: destructive/branch guard อ่าน state ก่อนคำสั่งรัน → `git checkout -b && git commit` ก้อนเดียวโดน block (เห็น branch develop). แยกคำสั่ง — **Why**: guard ตัดสินตอน hook fire ไม่ใช่หลัง compound. promoted → `.ai/shared/LESSONS.md`.
- **Discovery**: clone โมดูลแบบ isolated = `cp -R` dir + `sed` rewrite เฉพาะ absolute cross-namespace import (`@/components/role`→`@/components/producer-role` ฯลฯ) + `/user/role`→`/producer/role`; relative cross-import (`./role-badge`) รอดเอง เพราะ basename ไม่เปลี่ยน. isolation gate = grep leftover ref ต้อง = 0 — **Why**: clone 14 components + 8 routes ผ่านรอบเดียว build เขียว. (nav dual-config + client-boundary มีใน `nextjs.md` แล้ว ไม่ promote ซ้ำ.)
