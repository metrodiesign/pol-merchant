## Lessons Learned

- **Pattern**: read-only view ที่ clone จาก form view — ห้าม import component ของ module อื่น (เช่น CheckoutCard เข้า transaction view) เพราะนำ "use client" contamination + cross-module coupling มาด้วย; สร้าง local helper ขนาดเล็ก (Panel, ReadField) ที่ mirror visual เดียวกันแทน — **Why**: Server Component ใน App Router สูญ server-render ทันทีที่ import "use client" component จาก module อื่น; ถ้าเลิกใช้ helper ในรอบถัดไปก็ลบได้เลยไม่มี coupling

- **Discovery**: `ReadField` helper ที่สร้างเพื่อ read-only input-style ถูก user ต้องการเปลี่ยนเป็น bold text ทีหลังในทุก field — ถ้า requirement ระบุ "read-only view" ควรถามก่อนว่า ต้องการ visual style เหมือน input box หรือ plain text เพราะกระทบ helper ทั้ง component — **Why**: สร้าง ReadField ไปทั้ง component แล้วต้อง refactor ออกทั้งหมดในรอบเดียวกัน
