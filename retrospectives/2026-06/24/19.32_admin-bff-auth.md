## Lessons Learned

- **Discovery**: คู่มือ integration ของ backend อาจไม่ครบ contract — `admin-fe-integration.md` ไม่ระบุ route `/login-error` + reason codes (อยู่ใน backend source `AdminAuthOptions`/`AdminLoginService`). เจอตอน live E2E จริง (404). — **Why**: ก่อนประกาศ done ให้ cross-check คู่มือ FE กับ backend source ในเส้น error/redirect/callback (ไม่ใช่แค่ happy path).
- **Pattern**: validate FE integration ด้วย contract-mock backend (no-dep http server พูดตาม contract) เมื่อ real backend ต้อง human-auth/DB (OIDC+Google) — exercise ครบทุก path (proxy/guard/401/CSRF/authed) แบบ deterministic. — **Why**: real backend ที่ login ไม่ได้ validate ได้แค่ 401 path; mock ครอบ authed + CSRF ที่ automate ไม่ได้ด้วย Google จริง.
- **Pattern**: CI ที่ loop ทุก spec (spec-trace) → sibling spec ที่พังจะ red ทุก PR. ก่อนรับเป็นความผิดตัวเอง เช็ค `git diff base...HEAD -- <failing-area>` ว่าง = pre-existing. — **Why**: กันแก้ของที่ไม่ใช่ของเรา / กันเข้าใจผิดว่า PR เรา regress.
- **Discovery**: same-origin proxy (Next rewrites) ทำให้ /admin/* เป็น same-origin ในสายตา browser → CORS origin mismatch (doc เขียน 5130 vs จริง 5200) ไม่มีผล. — **Why**: ปัญหา CORS ส่วนใหญ่หายไปด้วย proxy; ไม่ต้องไล่ debug CORS เมื่อใช้ same-origin BFF.
