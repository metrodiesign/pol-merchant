## Lessons Learned

- **Discovery**: Next.js Turbopack dev server zombie — process มีชีวิต, port bound, log ว่างเปล่า, serve HTTP 404 ทุก route แต่ body เป็น HTML จริง. `curl -s -o /dev/null -w "%{http_code}"` คืน 404 เหมือน route ไม่มี ทั้งที่ code ถูก. **Why**: อาการนี้แตกต่างจาก "route ไม่ exist" (ซึ่งก็ 404 เหมือนกัน) — diagnose โดย `curl -i` ดู body มี HTML ไหม; ถ้ามี HTML แต่ 404 = zombie. Fix = `kill <pid>` แล้ว restart สด.
