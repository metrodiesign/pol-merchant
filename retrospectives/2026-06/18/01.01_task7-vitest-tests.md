## Lessons Learned

- **Discovery**: GitHub MCP `issue_write` `method=create` + `state:"closed"` **ไม่ปิด issue ตอนสร้าง** — issue เกิดเป็น open เสมอ (state/state_reason ถูกเพิกเฉยบน create). ต้อง `method=update state=closed` แยกอีกรอบ. เช็กด้วย `gh issue list --state open` หลัง sync ทุกครั้ง. — **Why**: รอบแรก /spec-sync สร้าง #28-#33 ด้วย state=closed คิดว่าปิดแล้ว แต่จริงเปิดค้างทั้ง 6 (manifest บอก closed แต่ GitHub open = ไม่ตรง) เพิ่งจับได้ตอน `gh issue list`.
- **Pattern**: `task-gate.sh` บังคับทุก task ที่ mark `[x]` ต้องมีบรรทัด **`viewports:`** ใน Evidence แม้เป็น logic-only — ใส่ `viewports: n/a — logic-only`. — **Why**: mark task 7 (unit test ล้วน) โดน block เพราะ Evidence ขาด `viewports:`; gate parser หา keyword ตรงตัว.
- **Pattern**: reducer/logic ที่ฝังในไฟล์ hook (`"use client"` + import React component) test ตรงไม่ได้ใน env node — extract เป็น pure module (`cart.ts`) แล้ว hook import กลับ; test pure module เลี่ยงดึง React tree. — **Why**: import hook เข้า vitest จะลาก `policy-table-columns`(JSX)/base-ui เข้ามาพังใน node; extract = test ได้สะอาด + behavior เดิม.
