## Lessons Learned

- **Discovery**: test ที่ส่ง signal ข้าม process group (`workspace-verification.test.mjs` "cleanup closes detached descendant") fail เฉพาะใน Bash sandbox ของ Claude (`Missing expected exception`) แต่ผ่านเมื่อรัน `dangerouslyDisableSandbox` — และ `kill <pid>` ของ process นอก sandbox ก็ตอบ `operation not permitted` — **Why**: ก่อนสรุปว่า test แดงจากโค้ด ให้รันซ้ำนอก sandbox 1 ครั้ง; gate `npm test` ของ repo นี้ต้องรันนอก sandbox และต้องปิด dev server บน 3001 ก่อน
- **Pattern**: `scripts/spec-trace.sh` ต้องการบรรทัด `- Satisfies: REQ-x.y-x.z` ใต้ทุก task ใน tasks.md แยกจาก `Evidence:` — quick spec ที่เขียน REQ ID ไว้ในชื่อ task อย่างเดียวจะ fail 19/19 — **Why**: `/ship-pr` pre-flight รัน trace; ใส่ตั้งแต่ตอน `/spec-quick` step 4 ถูกกว่าแก้ตอน ship
- **Pattern**: card ที่ซ่อน checkbox ด้วย `sr-only` แล้วใส่ `focus-within:ring` บน label จะโชว์กรอบค้างหลังคลิก (checkbox ยัง focus อยู่) — ลอก class จากต้นแบบ (`checkout-channel-card.tsx`) เป๊ะ ไม่เติม focus ring เอง; ถ้าต้องการ a11y ใช้ `has-[:focus-visible]:` — **Why**: user รายงานเป็น bug ทันทีจาก class ที่ผมเติมเกินต้นแบบ
- **Pattern**: ก่อน mark `[x]` ใน tasks.md ตรวจว่า `npm test` เขียวได้จริงใน environment ปัจจุบัน (port ว่าง, sandbox) — `task-gate.sh` PostToolUse บล็อก Write แล้วไฟล์ยังถูกเขียน ต้องคืน `[ ]` เอง — **Why**: เสีย 1 รอบ flip/unflip เพราะ mark ก่อนรู้ว่า gate จะแดงจาก env
