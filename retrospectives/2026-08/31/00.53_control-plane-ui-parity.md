## Lessons Learned

- **Pattern**: จะ replicate visual pattern ข้าม N screen ให้ยก shared kit ขึ้นก่อน (toolbar, detail-shell, row-action, stat-card) จาก implementation แรกที่ user รับแล้ว (PSP) แล้วค่อยไล่ทีละ group — 10 screen ใช้ kit เดียว diff สุทธิเกือบเป็นศูนย์ (+1556/-1529) และ success criteria เป็น grep ได้ — **Why**: ทำ inline ต่อ screen แบบ PSP รอบแรกจะซ้ำ 10 ที่และ drift กันเอง
- **Pattern**: SSR markup test ด้วย `renderToStaticMarkup` + `test.each` ต่อ view (mock เฉพาะ `next/navigation`) ครอบ parity ทั้ง 16 view ใน 1 ไฟล์ — store ที่ใช้ `useSyncExternalStore` ต้องมี `getServerSnapshot` (repo นี้มี) ถึง render ได้ — **Why**: หน้า `/control/*` ติด SSO ถ่าย screenshot ไม่ได้ test นี้เป็น regression guard เดียวที่รันใน CI
- **Discovery**: process ที่จะ kill อาจจบไปเองระหว่างรอ user ตอบ (`kill: no such process`) — เช็ค `lsof` ซ้ำก่อน kill และก่อนรายงานว่า "หยุดให้แล้ว" — **Why**: รายงานผิดว่าเป็นคนหยุด dev server ทั้งที่มันจบเอง
